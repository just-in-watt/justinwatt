# Nom et identité JustInWatt

La licence Apache-2.0 couvre le code et la documentation originale du dépôt.
Elle n'accorde pas de droit supplémentaire sur le nom, les logos ou les signes
distinctifs JustInWatt.

Les forks peuvent indiquer factuellement leur origine, mais ne doivent pas se
présenter comme une version officielle, approuvée ou maintenue par le projet.
Ils doivent choisir un nom distinct lorsqu'une confusion est possible.

Le nom public retenu est `JustInWatt` et l'organisation GitHub
[`just-in-watt`](https://github.com/just-in-watt) a été réservée le 5 septembre
2026. Aucun domaine n'a été acheté et cette réservation ne constitue ni une
recherche juridique exhaustive, ni un dépôt de marque.

Une [vérification préliminaire datée](docs/governance/justinwatt-name-screening-2026-09-05.md)
n'a relevé aucune collision exacte pertinente dans les registres et espaces
logiciels consultés. Elle a en revanche confirmé que `JustinWatt`, sans tiret,
est déjà employé comme identité personnelle sur GitHub. La préparation privée
peut continuer, mais une recherche de similarités reste requise avant une
annonce publique significative ou un éventuel dépôt de marque.

Le changement répond notamment au risque de confusion avec le projet open
source antérieur `SolarPILOT`, sans lien avec ce dépôt. Les identifiants
techniques historiques `solarpilot` restent temporairement présents pour la
compatibilité selon l'ADR 0184 ; ils ne désignent pas une marque publique
concurrente.
