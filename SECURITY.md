# Politique de sécurité

## Signaler une vulnérabilité

Ne publiez pas de vulnérabilité, de secret ou de détail sur une installation
réelle dans une issue. Le signalement privé GitHub du futur dépôt public doit
être activé, vérifié puis référencé ici avant la première publication. Tant que
ce canal n'existe pas, la porte de publication reste fermée et aucune issue
publique ne doit servir de solution de remplacement.

Indiquez une description minimale, la version concernée, les conditions de
reproduction assainies et l'impact possible. N'incluez jamais d'identifiant ou
de trace domestique. Les mainteneurs accuseront réception et communiqueront un
plan adapté à la gravité, sans promettre un délai fixe avant qualification.

## Périmètre supporté

JustInWatt est en développement avant version 1.0. Seule la branche principale
courante reçoit les correctifs de sécurité. Les prototypes, branches anciennes,
intégrations non qualifiées et installations personnelles ne constituent pas
des versions supportées.

## Recherche responsable

N'effectuez aucun scan réseau, test destructif, contournement d'authentification
ou commande sur un équipement qui ne vous appartient pas. N'utilisez que vos
propres simulateurs et données fictives. Une autorisation de consulter le code
n'est pas une autorisation d'accéder à une installation.

En cas de comportement physique inattendu, reprenez immédiatement la main avec
les contrôles officiels du fabricant et les protections électriques prévues.
N'attendez pas une réponse du projet pour mettre une installation en sécurité.
